# 7EVEN BRAND: COMPREHENSIVE UI DESIGN SYSTEM & BLUEPRINT

This document serves as the absolute source of truth for the visual language of the 7EVEN brand website. It contains exact CSS values, layered effects, and structural styling rules. This guide is designed so that any new component or view can be built to look flawlessly native to the brand.

---

## 1. CORE VISUAL PHILOSOPHY
**Theme:** Premium Frost Titanium Glass — Limitless Borderless Edition.
**Aesthetic:** Industrial Brutalism fused with High-End Luxury Tech-Noir.
**Key Principles:** 
*   **Weightlessness & Depth:** Elements float via intense backdrop blurring and multi-layered shadows. Zero hard borders are used for structure.
*   **Tactile Metal & Glass:** Surfaces simulate brushed liquid metal, frosted dark glass, or etched titanium.
*   **Electric Micro-interactions:** User actions trigger sharp, analog "zap" flashes and neon flares instead of standard soft fades.

---

## 2. EXACT COLOR PALETTE

### Backgrounds & Void Spaces
The canvas should feel like an infinite, borderless void.
*   **Absolute Void (Body):** `#0A0A0A`
*   **Deep Shadow/Core (Overlays):** `#000000` (often used at 0.9 or 0.92 opacity for modals)
*   **Top Bar Frost:** `rgba(8, 8, 8, 0.9)`

### Typography & Iconography
Text should look like laser-etched metal catching the light.
*   **Primary Text (Body):** `#E5E5EA` (Crisp metallic light silver-white)
*   **Secondary Text (Subtitles/Prices):** `#C8C8D0` (Deeper silver)
*   **Muted Text (Placeholders/Descriptions):** `#B0B0B0` or `#888` at `opacity: 0.5`
*   **Hover States (Links):** Shifts from `#D8D8D8` to `#C8C8D0` with `text-shadow: 0 0 8px rgba(200, 200, 208, 0.4)`
*   **Inverted Text (On Light Buttons):** `#000` or `#1A1A1A`

### Accents & Strokes
*   **Base Borders/Strokes:** `rgba(200, 200, 208, 0.2)` or `rgba(255, 255, 255, 0.08)`
*   **Metallic Surface (Buttons):** `#181818` to `#222222`
*   **Active/Glow Color:** `#C8C8D0` (Used for active states, electric flares, and intense hover borders)

## 3. TYPOGRAPHY & THE "LASER ETCHED" EFFECT

The brand relies heavily on font manipulation to achieve an industrial, precision-machined look.

### Display & Signals (Font: `Doto`)
Used for logos, massive section titles, prices, and critical labels.
*   **Weight:** `700`
*   **Letter Spacing:** Ranges from `0.05em` (standard) up to `5px` or `10px` (massive headers).
*   **Text Shadow (Depth):** `0 1px 3px rgba(0, 0, 0, 0.9)` (Creates a drop shadow that separates the text from the glare of the glass behind it).

### Narrative & Body (Font: `Manrope`)
Used for buttons, inputs, paragraphs, and product titles.
*   **Body Weight:** `350`
*   **Titles/Buttons Weight:** `400`
*   **Inputs Weight:** `200`
*   **Letter Spacing:** `0.02em`
*   **Line Height:** `1.7`

### Signature Technique: "Laser Etched Distortion"
Almost all text (buttons, titles, labels) must apply this transform to look correctly branded. It stretches the font horizontally and squashes it vertically.
```css
transform: scale(1.05, 0.9);
transform-origin: left center; /* Use 'center center' if the text is horizontally aligned to center */
```

## 4. SURFACES, TEXTURES, & GLASSMORPHISM

Components (Cards, Modals, Shop Items) do not use flat colors. They are built using multi-layered CSS background textures and heavy backdrop filters.

### 4A. Standard Frost Titanium Glass (Cards & Shop Items)
Use this for floating items.
*   **Background Base:** 
    ```css
    repeating-linear-gradient(90deg, transparent 0, transparent 2px, rgba(255, 255, 255, 0.04) 2px, rgba(255, 255, 255, 0.04) 3px),
    linear-gradient(135deg, rgba(48, 48, 56, 0.45) 0%, rgba(12, 12, 15, 0.05) 100%)
    ```
*   **Blur Filter:** `backdrop-filter: blur(24px); -webkit-backdrop-filter: blur(24px);`
*   **Border:** `none` (Separation relies entirely on shadow)
*   **Default Shadow:** `0 15px 35px rgba(0, 0, 0, 0.45), 0 0 25px rgba(255, 255, 255, 0.01)`
*   **Hover Shadow:** `0 25px 50px rgba(0, 0, 0, 0.65), 0 0 35px rgba(255, 255, 255, 0.06)`

### 4B. Dark Brushed Liquid Metal (Contact Containers & Hero Elements)
A denser, darker metal effect.
*   **Background Base:**
    ```css
    repeating-linear-gradient(90deg, transparent 0, transparent 2px, rgba(255, 255, 255, 0.03) 2px, rgba(255, 255, 255, 0.03) 3px),
    linear-gradient(135deg, rgba(24, 24, 28, 0.85) 0%, rgba(12, 12, 16, 0.9) 100%)
    ```
*   **Blur Filter:** `backdrop-filter: blur(12px);`
*   **Border:** `1px solid rgba(255, 255, 255, 0.08)`
*   **Inset Shadows (Crucial for thickness):** 
    `inset 0 1px 0 rgba(255, 255, 255, 0.1), inset 0 0 30px rgba(200, 200, 208, 0.08), 0 10px 40px rgba(0, 0, 0, 0.6)`

### 4C. Dithered Radial Glows (Image Backgrounds)
Used to avoid color banding when displaying images inside expanded views.
*   **Background Base:**
    ```css
    url("data:image/svg+xml,%3Csvg viewBox='0 0 250 250' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noise'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.75' numOctaves='3' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noise)' opacity='0.035'/%3E%3C/svg%3E"),
    radial-gradient(circle at center, #3a3a46 0%, #22222b 35%, #131318 65%, #08080a 100%)
    ```
*   **Image Effect:** Images placed on this background must have `filter: drop-shadow(0 20px 30px rgba(0,0,0,0.6));` to "pop" off the gradient.

## 6. ANIMATIONS & "THE WOW FACTOR"

The brand uses aggressive, sudden animations rather than slow, soft fades. The primary effect is the "Electric Zap".

### 6A. The Electric Zap Keyframe (Used on Buttons/Interactions)
When an element is clicked or activated, it should undergo this precise shadow and color manipulation to simulate a power surge.
```css
@keyframes electric-zap {
    0% {
        box-shadow: 0 0 0 0 rgba(200, 200, 208, 0);
        border-color: rgba(200, 200, 208, 0.2);
        background: linear-gradient(135deg, #222222 0%, #181818 100%);
    }
    10% { /* The Flash / Locked In */
        box-shadow: inset 0 0 20px rgba(255, 255, 255, 0.5), 0 0 30px 5px rgba(200, 200, 208, 0.6);
        border-color: #ffffff;
        background: #111;
        color: #fff;
    }
    40% { /* The Spread */
        box-shadow: inset 0 0 10px rgba(200, 200, 208, 0.3), 0 0 50px 15px rgba(200, 200, 208, 0.3);
        border-color: #C8C8D0;
    }
    100% { /* Return to Base */
        box-shadow: 0 0 0 0 rgba(200, 200, 208, 0);
        border-color: rgba(200, 200, 208, 0.2);
        background: linear-gradient(135deg, #222222 0%, #181818 100%);
    }
}
```

### 6B. The Laser Scan / Zap Bolt (`::after` Pseudo-element)
Used in tandem with the zap keyframe, this overlays a physical beam of light sliding across the element.
*   **Gradient:** `linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.4), rgba(255, 255, 255, 0.8), rgba(255, 255, 255, 0.4), transparent)`
*   **Skew & Filter:** `transform: skewX(-20deg); filter: blur(2px); mix-blend-mode: overlay;`
*   **Animation:** Slides `left` from `-150%` to `150%` in `0.6s ease-out`.

### 6C. The Subtle Pulse (Used on indicators, volume bars, loading states)
*   **Animation:** 
```css
@keyframes subtle-pulse {
    0% { opacity: 0.8; box-shadow: 0 0 4px #C8C8D0; }
    50% { opacity: 1; box-shadow: 0 0 12px #C8C8D0, 0 0 20px rgba(200, 200, 208, 0.4); }
    100% { opacity: 0.8; box-shadow: 0 0 4px #C8C8D0; }
}
```

## 7. INTERACTIVE STARFIELD & COMETS (HTML5 Canvas)

The deep space background isn't static; it's a dynamic, interactive HTML5 canvas engine that creates spatial depth and life behind the floating glass panels.

### 7A. The Starfield Engine
*   **Density:** Exactly 182 stars rendered simultaneously to fill the void without clutter.
*   **Standard Stars (80% of volume):** 
    *   **Color:** Grayscale `rgba(180, 180, 185, ALPHA)`.
    *   **Size:** Ranging from `0.5px` to `1.8px`.
    *   **Twinkle:** Alpha opacity smoothly pulses between `0.03` and `0.55`.
*   **"Diamond" Super Shiny Stars (20% of volume):** 
    *   **Scale:** Base size is multiplied by `1.5x` to make them intensely prominent.
    *   **Colors:** Randomly selected from a premium light-dispersion palette: Diamond Silver-White, Light Blue, Pale Gold, Pale Violet, and Pale Aquamarine.
    *   **Twinkle:** Alpha opacity pulses much brighter, peaking at `1.0`.
*   **Diamond Lens Flare Shape:** Instead of simple circles, these super shiny stars are drawn using complex canvas paths to create sharp, 4-pointed beams with an inner core glow. This simulates actual anamorphic lens flares.
*   **Motion & Mouse Interaction:** All stars drift slowly upwards (`-0.03` to `-0.09` speed) with a slight horizontal sway. They react to the user's cursor, repelling away smoothly if the mouse enters a `150px` radius, adding a tactile feel to the background.

### 7B. Shooting Stars (Comets)
*   **Rarity & Elegance:** Sporadic spawn rate (`Math.random() < 0.0025` per frame) to ensure they feel special and not chaotic. Maximum of 2 allowed on screen at once.
*   **Spawn Rules:** Emerge from the upper 30% of the screen on the left side, diving downwards.
*   **Trajectory:** Fast motion (speed `15` to `30`) locked at an angle of `30` to `45` degrees.
*   **Visual Anatomy of the Comet:**
    *   **The Trail:** A long `120px` to `270px` line stroke using a linear gradient that fades from solid white `rgba(255, 255, 255, 1)` at the head to completely transparent at the tail.
    *   **The Burning Tip:** The head of the comet is drawn with two overlapping circles to simulate heat: a soft outer glare halo at 45% opacity, and an intense, focused inner core spark at 100% opacity.
