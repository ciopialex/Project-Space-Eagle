# Security

Please report a vulnerability privately: on this repository's **Security** tab,
choose **Report a vulnerability**. Do not open a public issue for it.

What is worth reporting: a way to make the eagle run something the user did not
ask for, read or send data it should not, or bypass a confirmation before an
action that cannot be undone.

Where things live, for a report: your keys and memory are in the platform data
folder (`%LOCALAPPDATA%\Aethelark`, `~/Library/Application Support/Aethelark` or
`~/.local/share/aethelark`), owner-only, never inside the app folder. The phone
remote is off by default.
